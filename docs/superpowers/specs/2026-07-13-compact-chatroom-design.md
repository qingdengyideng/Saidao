# 聊天室紧凑样式设计

## 目标

在不改变聊天室功能和消息结构的前提下，降低消息、顶部和输入区的垂直占用，让单屏显示更多内容，并适配不同宽度的手机。

## 范围

- 仅修改 `assets/css/main.css` 中的聊天室视觉样式。
- 不修改 `index.html` 的聊天室结构，也不修改 `assets/js/app.js` 的消息渲染、历史加载、发送、引用、图片过滤或语音播放逻辑。
- `Hot` 热词栏保持默认展示；内容超宽时沿用横向滚动。

## 布局

采用平衡紧凑密度：保留头像、昵称、时间和完整输入控件，同时压缩非必要留白。

在桌面侧栏及视口宽度大于 576px 时：

- 聊天头部内边距从 `18px` 调整为 `12px`。
- Hot 栏最小高度从 `52px` 调整为 `42px`，并缩小其内边距和标签尺寸。
- 消息区内边距从 `18px` 调整为 `12px`。
- 头像从 `45px` 调整为 `34px`。
- 单条消息底部间距从 `15px` 调整为 `8px`。
- 气泡内边距从 `8px 12px` 调整为 `5px 9px`，正文使用 `14px` 和 `1.4` 行高。
- 输入区缩小 footer 的间距与内边距，但不缩小主要交互控件的可点击范围。

在视口宽度不超过 576px 时：

- 聊天侧栏继续全屏显示。
- 消息区横向内边距为 `10px`，头像为 `30px`。
- 昵称、时间和正文分别使用紧凑的 `12px`、`10px`、`13px/1.4` 尺寸。
- 气泡最大宽度按可用容器计算，长昵称、时间和正文可换行或截断，不产生横向溢出。

在视口宽度不超过 350px 时：

- 消息区横向内边距降为 `8px`，头像降为 `28px`。
- 保持 Hot 栏横向滚动、输入框及发送按钮可见可用。

## 特殊消息

图片、语音、系统消息、已删除占位和引用块同步缩小间距或内边距，使其与普通文本消息保持一致的密度。图片和语音自身的可用尺寸不做会影响使用的压缩。

## 兼容性

- 深色模式继续使用当前 CSS 变量和已有深色选择器。
- 不新增接口、持久化状态或密度切换控件。
- 不影响现有移动端全屏聊天、Hot 展开状态和聊天滚动行为。

## 验证

在 `320px`、`375px`、`430px` 宽度及桌面侧栏下检查：

- 多行文本、长昵称和时间信息不产生横向溢出。
- 输入区、表情、录音和发送控件可用且不遮挡。
- 普通文本、图片、语音、系统、引用和图片隐藏消息均未裁切。
- 浅色和深色模式均保持可读性。
