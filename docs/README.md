# Docs 目录说明

| 目录            | 用途                                                                                 |
| --------------- | ------------------------------------------------------------------------------------ |
| `api/`          | 赛道（Saidao）前端接口总览：各模块接口文档、统一请求约定、鉴权模型、速查表           |
| `schema/`       | 机器可读规范：`openapi.yaml`（OpenAPI 3.0，覆盖全部 REST 接口 + WebSocket 消息格式） |
| `specs/`        | 业务地图（要做什么）                                                                 |
| `plans/`        | 计划与方案                                                                           |
| `architecture/` | 系统怎么连的（8 类连接点）                                                           |
| `runbook/`      | 零散过程知识（8 类）                                                                 |
| `logs/`         | 日志记录                                                                             |
