# 01 · 产品总览与架构

> Saidao（抽象赛道网）产品架构 / 功能地图 / 信息架构

---

## 1. 产品定位

Saidao 是一个以「**主播直播 + 实时聊天室**」为核心的互动社区站点。用户浏览全网主播直播卡片，进入聊天室实时互动（文字/语音/表情/投票），可进入独立播放页观看带弹幕的直播。同时集成抽象日报（AI 生成）、红蓝掰头投票、聊天时间线等社区玩法。

**核心价值主张**：
- **聚合**：聚合多平台（B站/Youtube 等）主播直播，统一卡片入口
- **陪伴**：实时聊天室 + 弹幕，营造直播间陪伴感
- **玩法**：掰头投票、时间线、抽象日报等社区互动

**产品调性**：年轻化、社区化、带「抽象」亚文化色彩（日报名「抽象日报」、提示语「来嘟两句呗」等）。

---

## 2. 用户角色

| 角色 | 权限位 | 能力 |
|------|--------|------|
| **游客** | — | 浏览主播卡片、看直播/弹幕；聊天受限（发消息可能触发验证码）；不能投票/创建掰头/编辑资料 |
| **注册用户** | `isLoggedIn` | 聊天（文字/语音/表情）、屏蔽设置、掰头投票、编辑资料、选阵营、配置 webhook、上传头像/表情 |
| **有权限用户** | `canChatBan=true` | 额外：封禁用户（1小时/7天）、删除消息、屏蔽操作 |
| **运营/管理员** | `canEditSaidaoTag=true` | 额外：编辑主播标签 |

> 权限位来自 `GET /user/` 返回的 user 对象，存于 `state.currentUser`。游客无 token，401 请求统一弹登录框。

## 3. 功能地图

```
Saidao
├── 浏览与发现
│   ├── 主播直播卡片列表（直播中/全部/抽象日报 三 tab）
│   ├── 卡片内嵌 HLS/FLV 实时预览
│   ├── 点击跳转独立播放页
│   ├── 热度分实时排序 ▲
│   ├── 主播标签 / 封面 / AI 内容分析 实时更新 ▲
│   └── 抽象日报列表（AI 生成，新日报红点）
│
├── 实时聊天室（首页右侧/移动端全屏）
│   ├── 消息：文字 / 系统 / 语音 / 图片 / 链接预览 / 引用 / @
│   ├── 上下文菜单（复制/引用/@/屏蔽用户/屏蔽IP/封禁/删除）
│   ├── 输入区：自动增高 / Enter 发送 / Ctrl+Enter 换行
│   ├── 语音消息（MediaRecorder 1~60s + 波形）
│   ├── 表情（常用/动画/VIP 三组 + 自定义上传）
│   ├── 屏蔽设置（用户/昵称/IP属地/关键词正则/游戏直播）
│   ├── 历史消息（滚动加载 / 回放窗口 / 回到最新）
│   ├── 时间线（近 2 小时 AI 话题摘要，60s 轮询）
│   ├── 红蓝掰头投票（创建/投票/历史/倒计时）
│   ├── Hot 热词栏（WS 推送，点击高亮定位）
│   ├── 在线人数 ▲
│   └── 滑动验证码（发消息触发人机验证）
│
├── 独立播放页（player.html）
│   ├── HLS/FLV 播放（hls.js / mpegts.js / flv.js）
│   ├── 直播状态机（连接中/直播中/等待开播/连接中断）
│   ├── 弹幕（车道制 90px/s，评论同源投影）
│   ├── 评论面板（实时，含用户名）
│   ├── 小窗 PiP（Document Picture-in-Picture）
│   ├── 全屏（标准/webkit/iOS原生/CSS假全屏 降级链）
│   ├── 音量 / P 键声音快捷键
│   └── 移动端适配（非 youtube 跳源站）
│
├── 账号体系
│   ├── 登录（账号/邮箱 + 密码）
│   ├── 账号分配（自动分配 + 6位初始密码 + 图形验证码）
│   ├── 图形验证码（/user/captcha）
│   ├── 滑动验证码（/captcha/slider + verify）
│   ├── 个人信息（头像/昵称/签名/阵营/开播通知 webhook）
│   ├── 修改密码
│   └── 用户详情（聊天点头像查看）
│
├── 赛道管理（运营向）
│   ├── 主播标签编辑（canEditSaidaoTag）
│   ├── 「不想看TA」屏蔽（notShow）
│   ├── 游戏直播屏蔽（contentAnalysis.isGame）
│   └── 热度分 / AI 内容分析 实时应用
│
├── 视频点播室（当前休眠，代码保留）
│   ├── BV 号提交
│   ├── 投票（赞成/反对）
│   ├── 播放队列 + 当前播放
```

## 4. 页面导航流

```
                         ┌─────────────────────────┐
                         │      主页 index.html      │
                         │  头部 + 筛选 tabs + 卡片   │
                         │  + 右侧聊天室             │
                         └───────────┬─────────────┘
              ┌──────────────┬───────┼──────────┬──────────────┐
              │              │       │          │              │
        点头像/昵称      点卡片    点头部按钮   聊天操作     点日报卡片
              │              │       │          │              │
              ▼              ▼       ▼          ▼              ▼
     ┌──────────────┐ ┌────────┐ ┌────────┐ ┌──────────┐ ┌─────────┐
     │ 用户详情弹窗  │ │ 播放页 │ │ 赞助页 │ │ 各类弹窗  │ │ 新标签页  │
     │ userDetail   │ │player │ │sponsor │ │登录/资料/ │ │ 打开日报  │
     │ (modal)      │ │ .html │ │ .html  │ │掰头/时间线│ │  link     │
     └──────────────┘ └───┬────┘ └───┬────┘ └──────────┘ └─────────┘
                          │          │
                     去源站 │      返回首页│
                          ▼          ▼
                     主播源站     主页
                     (新标签)
```

**导航要点**：
- **主页 ↔ 播放页**：点卡片封面区 → `window.open(url, '_blank')`（新标签页）
- **主页 ↔ 赞助页**：头部心形按钮 → `location.href = 'sponsor.html'`（整页跳转）；赞助页「返回首页」→ `/`
- **弹窗内不跳转**：登录/资料/掰头/时间线/用户详情均为 modal 覆盖，不改变页面
- **日报**：新标签页打开外部 link

## 6. 核心交互闭环

### 6.1 观看闭环
```
浏览卡片 → hover/点击预览 → 点封面进播放页 → 看直播+弹幕+评论
   ▲                                              │
   │                                         去源站/小窗/全屏
   └──────────── 返回主页继续互动 ◄────────────────┘
```

### 6.2 互动闭环（聊天室）
```
输入 → 发送(WS) → 服务端(可能要求验证码) → 广播 → 所有客户端渲染
   │                                                    │
   └─ 语音录制/表情/引用/@ ──────────────────────────────┘
        屏蔽设置过滤本地渲染，被屏蔽消息仍可恢复
```

### 6.3 实时驱动（WS 广播 → UI）
```
/ws/chat 下行 12+ 种 type
  ├── user/system → 聊天消息渲染
  ├── status → 主播上下播 → 刷新卡片
  ├── onlineCount → 在线人数
  ├── hotWords → 热词栏
  ├── dailyReportUpdate → 日报刷新+红点
  ├── pollUpdate → 掰头刷新
  ├── saidaoTag/Cover/ContentAnalysis/hotScore → 卡片实时更新
  └── clear/messageDeleted → 消息清理
```

## 7. 非功能需求（现状基线）

| 维度 | 现状要求 | 重构保留项 |
|------|----------|------------|
| **实时性** | WS 广播毫秒级；轮询（时间线 60s / 掰头 15s / 1s 倒计时） | WS 为主，减少轮询 |
| **离线** | PWA 缓存表情/图片/Lottie；离线图片降级 1×1 透明 PNG | 保留 PWA + SW |
| **性能降级** | 触屏不自动预览；FLV/HLS 库不可用降级；弹幕车道全占丢弃；评论 200 条裁剪 | 保留降级链 |
| **安全** | 设备指纹 fp 风控；滑动验证码防刷；token 鉴权；引用图仅 https | 保留，鉴权可升级 Bearer |
| **可访问性** | aria-label/role、键盘可达（焦点陷阱、Escape）、P 键快捷键 | 保留并完善 |
| **响应式** | 桌面（侧栏）/ 移动端（≤768 全屏聊天、跳源站） | 保留 |
| **多主题** | 浅色/深色（`data-theme`），CSS 变量 | 保留并梳理 token |

**已知风险点（重构应修复）**：
- 弹幕/评论 `innerHTML` 渲染 user/text，存在 HTML 注入面 → 重构须转义或用框架自动转义
- `registerDate` 秒级时间戳未 ×1000 可能显示 1970 → 需修正
- 后端异常回显 SQL 堆栈（videoRequest/submit）→ 前端需容错，建议后端屏蔽
- `m3u8` 未开播返回字符串 `"null"` → 前端须特殊处理
- 双份聊天逻辑 → 重构统一
- 登录/资料保存后 `location.reload()` 重建状态 → 重构改局部状态同步

## 8. 技术约束（重构选型参考）

| 约束 | 说明 | 重构建议 |
|------|------|----------|
| 无构建框架 | 原生 JS + CDN 库（hls.js/mpegts.js/flv.js/FingerprintJS） | 引入构建（Vite）+ 包管理 |
| 组件化缺失 | 15 个 JS 文件全局挂载，`app.js` 169KB 超大 | 组件化拆分（卡片/聊天室/播放器/弹窗） |
| 状态管理缺失 | 全局 `window.SaidaoState` | 引入 store（状态+副作用） |
| 样式散乱 | 6 个全局 CSS + 行内 style 混用 | 设计 token + 组件样式（CSS Modules/styled） |
| 流媒体 | hls.js + mpegts.js + flv.js 三库并存 | 统一封装播放引擎接口 |
| 实时通信 | 原生 WebSocket，手写重连/竞态 | 封装 WS 客户端（重连/心跳/消息路由） |
| PWA | 原生 SW + manifest | 保留，可用 vite-plugin-pwa |
